# Roller Skate AutoCAD Project

## Overview
This project was created for my university course **Grafica Asistată de Calculator** (Computer-Aided Graphics). It includes a 2D and 3D reconstruction of a pair of roller skates inspired by the **Oxelo Fit 5 JR** model, developed using **Autodesk AutoCAD 2024**.

![Render1.png]
*Side-View Render of the Roller Skate*

The project helped me explore AutoCAD’s drafting and modeling tools, improve precision in technical design, and organize a complete CAD workflow.

---

## Project Structure
The repository is organized into the following folders:

- **2D Sketches/** – Contains 2D drawings of individual components.  
- **3D Models/** – Contains 3D components and the assembled model.  
  - Each component is included in two versions:  
    - a version with dimensions  
    - a version without dimensions  
  - Some parts include multiple dimensioned views for clarity.

All files are saved in **.dwg** format (AutoCAD 2018 or later).

---

## Model Description
The roller skate model includes the following main components:

- Wheels (in-line arrangement)  
- Bearings  
- Bolts and frame  
- Adjustable base for size extension  
- Plastic cuff with closing mechanism  
- Brake system

Dimensions for the bearings were sourced from an online retailer, while the remaining measurements were taken manually.

### Modeling Scales Used
| Component         | Scale |
|-------------------|--------|
| Bearings          | 8:1    |
| Wheels            | 2:1    |
| Bolts             | 4:1    |
| Closure system    | 2:1    |
| Cuff              | 1:2    |

The full project is presented at a **1:2 scale**, meaning 1 cm in the drawing represents 2 cm in reality. Smaller components were modeled at individual scales and later adjusted to fit the final assembly.

---

## Layers and Workspace
- The project uses the **acad.dwt** template with a **60×20 unit** workspace.  
- A custom dimension style (**ANNOTATION**) was created to improve readability.  
- The final assembly contains **23 layers**, each corresponding to a component.  
- Construction and guide lines were removed in the final files to maintain clarity.
